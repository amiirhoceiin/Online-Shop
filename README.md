# 📚 Bookstore Website

Welcome to the **Bookstore Website** — a React-based project for browsing, adding, and managing books. This project is part of my journey in mastering front-end development.

## 🚀 Features

- Browse books by title and author
- Add new books to the catalog
- Delete books from the list
- Responsive design (using CSS Grid and Bootstrap)
- Seamless user experience with React states and props

## 🛠️ Technologies Used

- **React.js** — Component-based UI development
- **Bootstrap** — For responsive styling
- **CSS Grid** — To handle layouts
- **Figma** — For design prototyping

## 📦 Project Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/your-repo.git
   cd your-repo
   ```
2. **Install dependencies:**
   ```bash
   npm install
   ```
3. **Run the development server:**
   ```bash
   npm start
   ```
4. **Build for production:**
   ```bash
   npm run build
   ```
## 🌐 API Integration

This project uses a Django backend for handling book data, developed in collaboration with a backend developer. The API endpoints allow fetching, adding, and deleting books, ensuring seamless integration between the frontend and backend.
